🧊 IceBreakers editor

No password or access token is stored here. Editing is local until you explicitly save through GitHub. Only authorised GitHub accounts can commit changes.

Publish changes

1. Copy the updated JSON. 2. Open the corresponding GitHub file. 3. Replace its entire contents with your copied JSON and click Commit changes. GitHub will require your normal sign-in and write permission. The live deck updates after GitHub Pages publishes.
